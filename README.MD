# Zona Fit Evolution - API Backend

Este proyecto es el backend para la aplicación Zona Fit Evolution, construido con Flask y siguiendo una arquitectura modular basada en rutas y modelos.

## Estructura
- `app/`: Lógica de la aplicación y modelos.
- `app/routes/`: Definición de los endpoints de la API.
- `database/`: Scripts SQL de la base de datos.
